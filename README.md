# Hybrid Quantum-Classical Machine Learning for Ransomware Detection

## 1. Project Overview

This project implements and evaluates a hybrid quantum-classical machine learning approach for ransomware detection. It compares the performance of a **Variational Quantum Classifier (VQC)** against three standard classical models: **Logistic Regression**, **Random Forest**, and **XGBoost**.

The primary goal is to analyze the effectiveness of quantum machine learning in a real-world cybersecurity context. The VQC's performance is systematically tested by varying the number of qubits, which also corresponds to the number of principal components used for feature reduction via PCA.

## 2. Repository Structure

The project is organized into the following directories:

-   `data/`: Contains the raw dataset.
    -   `ransomware_features.csv`: A CSV file with feature vectors extracted from software samples.
-   `src/`: Contains all the Python source code for the experiments.
    -   `run_classical_models.py`: Trains and evaluates the baseline classical machine learning models.
    -   `run_quantum_model.py`: Implements and runs the Variational Quantum Classifier (VQC) using Qiskit.
    -   `plot_final_results.py`: Generates the final comparison plot of VQC vs. classical model performance.
-   `results/`: Stores the numerical output from the model evaluations (e.g., performance metrics in JSON format).
-   `figures/`: Stores the plots and figures generated by the scripts (e.g., ROC curves, final comparison charts).

## 3. Setup and Installation

To run this project, you need a Python environment with the necessary libraries installed.

**Prerequisites:**
- Python 3.8+

**Dependencies:**
You can install the required libraries using pip:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn xgboost qiskit qiskit-machine-learning qiskit-algorithms
```
*Note: The scripts were developed using `qiskit>=1.0`.*

## 4. Usage: Step-by-Step Guide

Follow these steps to reproduce the experiments and generate all results and figures.

### Step 1: Run the Classical Models

This script will train the Logistic Regression, Random Forest, and XGBoost models. It evaluates them and saves a plot of their ROC curves to the `figures/` directory.

```bash
python src/run_classical_models.py
```

### Step 2: Run the Quantum Model

This script trains and evaluates the VQC. You can configure the number of qubits inside the script (`NUM_QUBITS` variable). The script will save the model's performance metrics as a JSON file in the `results/` directory.

**Note:** This script is computationally intensive and may take a significant amount of time to run, especially with a higher number of qubits.

```bash
python src/run_quantum_model.py
```
*(You may want to run this script multiple times with different `NUM_QUBITS` values (e.g., 4, 8, 12) to gather data for the final plot.)*


### Step 3: Generate the Final Comparison Plot

After running the quantum model for different qubit configurations and manually noting the results, this script generates the final plot comparing the VQC's recall against the best classical model. The data is currently hard-coded in the script but can be updated with new experimental results.

```bash
python src/plot_final_results.py
```
This will save the final performance comparison chart to the `figures/` directory.

## 5. Results

The experiments compare the models based on standard classification metrics like Accuracy, Precision, Recall, F1-Score, and AUC.

- The classical models, particularly **Random Forest**, achieve very high performance, with recall scores reaching over 97%.
- The VQC's performance is analyzed as a function of the number of qubits. The final plot (`figures/final_recall_vs_qubits.png`) shows how the VQC's recall and the explained variance from PCA scale with the qubit count.
- The results indicate that while the classical models currently outperform the VQC, the quantum classifier's performance improves as the number of qubits increases, suggesting potential for future quantum machine learning applications as hardware and algorithms mature.
